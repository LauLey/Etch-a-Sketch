# 🎨 Etch-a-Sketch

## Descripción

Etch-a-Sketch es una aplicación interactiva desarrollada con **HTML, CSS y JavaScript** que permite generar cuadrículas personalizadas para dibujar al pasar el cursor sobre cada celda.

La aplicación incluye un selector de color, un modo de colores RGB aleatorios con opacidad progresiva y la posibilidad de limpiar y regenerar el lienzo de dibujo mediante controles interactivos.

## ✨ Características

- Generación dinámica de cuadrículas.
- Dibujo al pasar el cursor sobre las celdas.
- Selector de color personalizado.
- Modo de colores RGB aleatorios.
- Incremento progresivo de la opacidad al pintar.
- Limpieza del lienzo.
- Regeneración de la cuadrícula con diferentes dimensiones.
